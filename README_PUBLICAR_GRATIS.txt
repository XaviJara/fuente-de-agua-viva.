FUNDACIÓN FUENTE DE AGUA VIVA — WEB V3
======================================

VERSIÓN
-------
Sitio estático (HTML + CSS + JavaScript + imágenes locales). No necesita WordPress, PHP ni base de datos.
Puede publicarse gratis en Netlify, Cloudflare Pages o GitHub Pages.

RECOMENDACIÓN PARA MANTENER COSTO $0: CLOUDFLARE PAGES
-------------------------------------------------------
1. Crea o inicia sesión en una cuenta gratuita de Cloudflare.
2. En el panel entra a Workers & Pages.
3. Elige Create application / Pages y la opción Direct Upload o Drag and drop.
4. Pon un nombre al proyecto, por ejemplo: fuente-de-agua-viva.
5. Arrastra la carpeta Fuente_de_Agua_Viva_Web_V3 o el ZIP.
6. Pulsa Deploy site.
7. Cloudflare entregará una URL temporal *.pages.dev.
8. Revisa Inicio, menú móvil, donaciones, WhatsApp, formulario, planos y páginas legales.
9. Cuando todo esté correcto, conecta www.fuentedeaguaviva.online como dominio personalizado.

OPCIÓN MÁS SIMPLE PARA ARRASTRAR Y SOLTAR: NETLIFY DROP
--------------------------------------------------------
1. Entra a https://app.netlify.com/drop
2. Inicia sesión o crea una cuenta gratuita.
3. Arrastra la carpeta completa Fuente_de_Agua_Viva_Web_V3 o el ZIP.
4. Netlify publicará el sitio y entregará una URL temporal *.netlify.app.
5. Desde Domain management puedes conectar www.fuentedeaguaviva.online.
Nota: Netlify dispone de plan gratuito, pero usa un sistema de créditos mensuales; revisa el consumo si el sitio crece.

ALTERNATIVA: GITHUB PAGES
-------------------------
- Sube todos los archivos a un repositorio público y activa Settings > Pages.
- Es útil si quieres mantener historial de cambios con Git.
